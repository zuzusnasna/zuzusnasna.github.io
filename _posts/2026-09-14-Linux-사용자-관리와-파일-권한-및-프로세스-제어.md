## Linux 사용자 관리와 파일 권한

## 1. 사용자 관리

Linux는 여러 사용자가 하나의 시스템을 함께 사용할 수 있는 운영체제입니다.

사용자마다 고유한 계정 정보와 권한을 가지며, 관리자는 사용자 계정을 생성하거나 삭제할 수 있습니다.

### 1.1 사용자 정보 확인

사용자 계정 정보는 `/etc/passwd` 파일에 저장됩니다.

```bash
cat /etc/passwd
```

사용자 이름만 확인하려면 `cut`을 사용할 수 있습니다.

```bash
cut -d: -f1 /etc/passwd
```

- `-d:` : 콜론(`:`)을 구분자로 지정
- `-f1` : 첫 번째 필드 출력

일반 사용자 계정을 확인하는 예시입니다.

```bash
awk -F: '$3 >= 1000 {print $1}' /etc/passwd
```

- `-F:` : 콜론을 필드 구분자로 지정
- `$3` : 세 번째 필드인 UID
- `{print $1}` : 첫 번째 필드인 사용자 이름 출력

UID 1000 이상을 일반 사용자 계정의 대략적인 기준으로 활용할 수 있습니다. 다만 배포판이나 시스템 설정에 따라 기준은 달라질 수 있습니다.

현재 사용자 확인:

```bash
whoami
```

현재 로그인한 사용자 목록:

```bash
who
```

### 1.2 사용자 생성

`adduser`는 새로운 사용자 계정을 생성하는 명령어입니다.

```bash
sudo adduser student1
```

사용자를 생성한 뒤 `id` 명령어로 정보를 확인합니다.

```bash
id student1
```

`id`를 통해 다음 정보를 확인할 수 있습니다.

- UID: 사용자 식별 번호
- GID: 기본 그룹 식별 번호
- Groups: 사용자가 소속된 그룹

### 1.3 사용자 삭제

`userdel`을 사용하여 사용자를 삭제할 수 있습니다.

```bash
sudo userdel student1
```

사용자의 홈 디렉터리까지 함께 삭제하려면 `-r` 옵션을 사용합니다.

```bash
sudo userdel -r student1
```

또는 Ubuntu에서 제공하는 `deluser`를 사용할 수도 있습니다.

```bash
sudo deluser --remove-home student1
```

삭제 여부 확인:

```bash
grep student1 /etc/passwd
```

검색 결과가 없다면 해당 계정이 `/etc/passwd`에 존재하지 않는 것입니다.

### 1.4 사용자가 삭제되지 않는 경우

사용자가 현재 로그인되어 있거나 해당 사용자의 프로세스가 실행 중이면 계정 삭제가 실패할 수 있습니다.

```text
userdel: user student1 is currently used by process 4253
```

이때 해당 사용자의 프로세스를 먼저 확인합니다.

```bash
ps -u student1
```

또는:

```bash
pgrep -a -u student1
```

특정 PID의 자세한 정보 확인:

```bash
ps -o pid,user,cmd -p 4253
```

사용자의 프로세스를 종료한 뒤 삭제할 수 있습니다.

```bash
sudo pkill -u student1
sudo userdel -r student1
```

주의: `pkill -u`는 해당 사용자의 여러 프로세스에 종료 신호를 보내므로 실행 중인 작업이 중단될 수 있습니다. 종료 전에 어떤 프로세스가 실행 중인지 확인해야 합니다.

## 2. 사용자 그룹 관리

그룹은 여러 사용자에게 공통 권한을 부여하고 관리하기 위한 기능입니다.

사용자를 그룹에 등록하면 그룹 단위로 파일과 디렉터리의 접근 권한을 관리할 수 있습니다.

### 2.1 그룹 확인

현재 사용자의 그룹 확인:

```bash
groups
```

특정 사용자의 그룹 확인:

```bash
groups student1
```

UID, GID, 소속 그룹을 함께 확인:

```bash
id student1
```

### 2.2 그룹 생성

`groupadd`는 새로운 그룹을 생성합니다.

```bash
sudo groupadd animals
```

### 2.3 사용자를 그룹에 추가

`usermod`를 이용하여 사용자를 그룹에 추가할 수 있습니다.

```bash
sudo usermod -aG animals dog
```

옵션 의미:

- `-a`: 기존 보조 그룹을 유지하면서 추가
- `-G`: 보조 그룹 지정

여기서 `-a` 없이 `-G`만 사용하면 기존 보조 그룹 목록이 새로 지정한 목록으로 대체될 수 있으므로 주의해야 합니다.

그룹 추가 여부 확인:

```bash
groups dog
```

그룹 변경 사항은 사용자의 기존 로그인 세션에 바로 반영되지 않을 수 있습니다. 로그아웃 후 다시 로그인하면 변경된 그룹 정보가 적용됩니다.

### 2.4 기본 그룹 변경

```bash
sudo usermod -g animals dog
```

`-g`는 사용자의 기본 그룹(primary group)을 변경합니다.

### 2.5 그룹에서 사용자 제거

```bash
sudo gpasswd -d dog animals
```

`dog` 사용자를 `animals` 그룹에서 제거합니다.

## 3. Linux 파일 권한

Linux에서는 파일과 디렉터리마다 접근 권한을 설정할 수 있습니다.

기본 권한은 읽기, 쓰기, 실행 세 가지입니다.

| 권한 | 의미 | 파일에서의 역할 | 디렉터리에서의 역할 |
|---|---|---|---|
| `r` | Read | 파일 내용 읽기 | 디렉터리 내부 목록 확인 |
| `w` | Write | 파일 내용 수정 | 내부 항목 생성·삭제·이름 변경 |
| `x` | Execute | 파일 실행 | 디렉터리 접근 및 탐색 |

권한은 다음 세 사용자 영역에 적용됩니다.

| 구분 | 의미 |
|---|---|
| `u` | 소유자(User) |
| `g` | 그룹(Group) |
| `o` | 기타 사용자(Others) |
| `a` | 모든 사용자(All) |

### 3.1 권한 확인

```bash
ls -l
```

실행 결과 예시:

```text
-rwxr-xr--
```

첫 번째 문자는 파일 종류를 나타내고, 나머지 9개 문자는 권한을 나타냅니다.

```text
- | rwx | r-x | r--
    소유자  그룹  기타 사용자
```

### 3.2 chmod를 이용한 권한 변경

`chmod`는 파일이나 디렉터리의 접근 권한을 변경하는 명령어입니다.

**문자 방식**

```bash
chmod u+x file
chmod g+w file
chmod o-r file
```

- `u+x`: 소유자에게 실행 권한 추가
- `g+w`: 그룹에 쓰기 권한 추가
- `o-r`: 기타 사용자의 읽기 권한 제거

모든 사용자에게 쓰기 권한 추가:

```bash
chmod a+w greetings
```

모든 사용자의 쓰기 권한 제거:

```bash
chmod a-w greetings
```

소유자와 그룹에 읽기·쓰기 권한 지정:

```bash
chmod ug=rw greetings
```

그룹의 쓰기 권한 제거:

```bash
chmod g-w greetings
```

**숫자 방식**

숫자 방식은 권한마다 지정된 값을 더하여 사용합니다.

| 권한 | 값 |
|---|---:|
| `r` | 4 |
| `w` | 2 |
| `x` | 1 |

권한 조합 예시:

| 숫자 | 권한 |
|---|---|
| 7 | `rwx` |
| 6 | `rw-` |
| 5 | `r-x` |
| 4 | `r--` |
| 0 | `---` |

예를 들어 다음 명령어를 실행하면:

```bash
chmod 755 file
```

권한은 다음과 같이 설정됩니다.

```text
소유자 : rwx = 7
그룹   : r-x = 5
기타   : r-x = 5
```

자주 사용하는 권한:

```bash
chmod 644 file
chmod 755 file
chmod 777 file
chmod 000 file
```

`777`은 모든 사용자에게 읽기·쓰기·실행 권한을 부여하므로 실제 서버에서는 신중하게 사용해야 합니다.

### 3.3 권한 변경 실습

파일 생성:

```bash
echo "hello" > greetings
```

현재 권한 확인:

```bash
ls -l greetings
```

모든 사용자에게 권한 부여:

```bash
chmod 777 greetings
```

권한 확인:

```bash
ls -l greetings
```

읽기 권한만 남기기:

```bash
chmod 644 greetings
```

모든 권한 제거:

```bash
chmod 000 greetings
```

파일 읽기 시도:

```bash
cat greetings
```

다음과 같은 오류가 발생할 수 있습니다.

```text
cat: greetings: Permission denied
```

다시 읽기 권한을 부여하면 파일을 확인할 수 있습니다.

```bash
chmod 644 greetings
cat greetings
```

## 4. chown을 이용한 소유자와 그룹 변경

`chown`은 파일이나 디렉터리의 소유자와 소유 그룹을 변경하는 명령어입니다.

기본 형식:

```bash
chown 사용자:그룹 파일
```

### 4.1 소유자 변경

```bash
sudo chown dog normal
```

파일의 소유자를 `dog`으로 변경합니다.

### 4.2 소유자와 그룹 변경

```bash
sudo chown dog:animals normal
```

소유자와 그룹을 함께 변경합니다.

### 4.3 하위 파일까지 재귀적으로 변경

```bash
sudo chown -R dog:animals /tmp/playground
```

`-R` 옵션은 지정한 디렉터리와 그 내부 항목에 변경을 재귀적으로 적용합니다.

### 4.4 chown과 usermod의 차이

```bash
sudo usermod -aG animals dog
```

사용자 `dog`을 `animals` 그룹의 구성원으로 추가합니다.

```bash
sudo chown dog:animals msg_from_dog
```

파일 `msg_from_dog`의 소유자를 `dog`, 소유 그룹을 `animals`로 변경합니다.

즉, `usermod`는 사용자 계정의 그룹 소속을 관리하고, `chown`은 파일과 디렉터리의 소유권을 관리합니다.

일반 사용자가 다른 사용자의 소유권을 임의로 변경하려 하면 `Operation not permitted` 오류가 발생할 수 있습니다. 이러한 관리자 작업에는 일반적으로 `sudo` 권한이 필요합니다.

## 5. sudo와 사용자 전환

`sudo`는 일반 사용자가 관리자 권한으로 명령어를 실행할 수 있도록 해주는 명령어입니다.

```bash
sudo userdel -r student1
```

모든 사용자가 `sudo`를 사용할 수 있는 것은 아닙니다.

권한이 없는 사용자가 실행하면 다음과 같은 오류가 나타날 수 있습니다.

```text
user is not in the sudoers file
```

사용자 전환은 `su` 명령어를 사용할 수 있습니다.

```bash
su dog
```

로그인 환경까지 함께 전환하려면 다음과 같이 사용합니다.

```bash
su - mango
```

현재 사용자를 확인하려면:

```bash
whoami
```

관리자 셸로 전환하는 방법:

```bash
sudo su
```

관리자 권한은 필요한 작업에 한해서 사용하는 것이 안전합니다.

## 6. 파일과 디렉터리 이동 및 이름 변경

`mv`는 파일이나 디렉터리를 이동하거나 이름을 변경하는 명령어입니다.

기본 형식:

```bash
mv [옵션] 원본 대상
```

### 6.1 파일 이동

```bash
mv file.txt test/
```

`file.txt`를 `test` 디렉터리로 이동합니다.

### 6.2 파일 이름 변경

```bash
mv old.txt new.txt
```

같은 디렉터리에서 대상 이름을 다르게 지정하면 이름이 변경됩니다.

### 6.3 이동하면서 이름 변경

```bash
mv old.txt test/new.txt
```

파일을 이동하면서 이름도 변경할 수 있습니다.

### 6.4 디렉터리 이름 변경

```bash
mv old_directory new_directory
```

디렉터리 이름을 변경합니다. 내부 파일은 그대로 유지됩니다.

### 6.5 여러 파일 이동

```bash
mv file1.txt file2.txt test/
```

여러 파일을 한 번에 지정한 디렉터리로 이동합니다.

### 6.6 자주 사용하는 옵션

```bash
mv -i file.txt test/
```

같은 이름의 파일이 존재하면 덮어쓰기 전에 확인합니다.

```bash
mv -n file.txt test/
```

기존 파일을 덮어쓰지 않습니다.

```bash
mv -v file.txt test/
```

이동 작업 내용을 출력합니다.

### 6.7 mv와 cp의 차이

| 명령어 | 동작 |
|---|---|
| `mv` | 원본을 이동하므로 기존 위치에서 사라짐 |
| `cp` | 원본을 유지하면서 복사본 생성 |

## 7. 프로세스 관리

프로세스(Process)는 실행 중인 프로그램을 의미합니다.

Linux에서는 여러 프로세스가 동시에 실행되며, 각각의 프로세스는 PID(Process ID)를 통해 구분됩니다.

### 7.1 ps를 이용한 프로세스 확인

`ps`는 현재 실행 중인 프로세스 정보를 확인하는 명령어입니다.

```bash
ps
```

모든 사용자의 프로세스 확인:

```bash
ps aux
```

특정 사용자의 프로세스 확인:

```bash
ps -u student1
```

특정 PID의 자세한 정보 확인:

```bash
ps -o pid,user,cmd -p 4253
```

### 7.2 PID

PID(Process ID)는 실행 중인 프로세스를 구분하기 위한 고유한 번호입니다.

프로세스 종료 명령어인 `kill`에서 특정 프로세스를 지정하는 데 사용합니다.

### 7.3 kill을 이용한 프로세스 종료

```bash
kill 4253
```

기본 `kill` 명령어는 기본적으로 `SIGTERM` 신호를 전달하여 프로세스에 정상 종료를 요청합니다.

강제 종료:

```bash
kill -9 4253
```

`-9`는 `SIGKILL` 신호를 의미하며 프로세스를 강제로 종료합니다.

일반적으로는 기본 `kill`을 먼저 사용하고, 정상 종료가 되지 않을 때 강제 종료를 고려합니다.

### 7.4 pgrep과 pkill

`pgrep`은 조건에 맞는 프로세스의 PID를 검색합니다.

```bash
pgrep -a -u student1
```

`pkill`은 조건에 맞는 프로세스에 종료 신호를 보냅니다.

```bash
sudo pkill -u student1
```

명령어 차이:

- `ps`: 프로세스 정보 확인
- `pgrep`: 조건에 맞는 PID 검색
- `kill`: 특정 PID에 신호 전달
- `pkill`: 조건에 맞는 프로세스에 신호 전달

프로세스를 강제로 종료하면 실행 중인 작업이 손실될 수 있으므로 종료 대상을 확인한 후 사용해야 합니다.

## 8. ping을 이용한 네트워크 연결 확인

`ping`은 특정 호스트에 ICMP Echo Request를 보내 응답 여부와 왕복 시간을 확인하는 명령어입니다.

### 8.1 IP 주소로 확인

```bash
ping 8.8.8.8
```

### 8.2 도메인으로 확인

```bash
ping google.com
```

### 8.3 요청 횟수 지정

```bash
ping -c 4 google.com
```

`-c` 옵션으로 요청 횟수를 지정할 수 있습니다.

### 8.4 결과 확인

```text
64 bytes from ...: icmp_seq=1 ttl=... time=...
```

- `icmp_seq`: 요청 순서
- `ttl`: 패킷의 TTL 값
- `time`: 요청부터 응답까지 걸린 시간

`ping`은 네트워크 연결 상태를 확인하는 데 유용하지만, 응답이 없다고 반드시 서버가 다운된 것은 아닙니다. 방화벽이나 네트워크 정책에 따라 ICMP 요청이 차단될 수도 있습니다.

## 핵심 정리

- `/etc/passwd`에서 사용자 계정 정보를 확인할 수 있습니다.
- `adduser`, `userdel`, `deluser`로 사용자 계정을 관리합니다.
- `id`, `whoami`, `who`, `groups`로 사용자 정보를 확인합니다.
- `groupadd`, `usermod`, `gpasswd`로 그룹을 관리합니다.
- `rwx`는 읽기, 쓰기, 실행 권한을 의미합니다.
- `chmod`는 파일과 디렉터리의 접근 권한을 변경합니다.
- `chown`은 파일과 디렉터리의 소유자 및 그룹을 변경합니다.
- `sudo`는 관리자 권한으로 명령어를 실행합니다.
- `mv`는 파일과 디렉터리를 이동하거나 이름을 변경합니다.
- `ps`와 `pgrep`은 실행 중인 프로세스를 확인합니다.
- `kill`과 `pkill`은 프로세스에 종료 신호를 전달합니다.
- `ping`은 네트워크 호스트의 ICMP 응답 여부를 확인합니다.

## 학습 흐름

```text
사용자 계정 확인 및 생성
        ↓
사용자 그룹 생성 및 관리
        ↓
파일 권한 확인 및 변경
        ↓
파일 소유자와 그룹 변경
        ↓
sudo 및 사용자 전환
        ↓
파일 이동 및 이름 변경
        ↓
프로세스 조회 및 종료
        ↓
네트워크 연결 확인
```
