## 프로젝트 개요

서로 다른 지역에 사는 사람들이 모임 장소를 정하고, 모임 후 귀가 경로와 막차 정보, 비용 정산까지 관리할 수 있도록 만든 웹 서비스다.

프로젝트는 현재 중단된 상태지만 외부 API와 캐시를 다루면서 많은 것을 배운 프로젝트였다.

## 주요 기능

- 모임방 생성 및 참여
- 참여자 출발 위치 등록
- 중간 지점 탐색
- 장소 후보 투표
- 최단 시간 / 최소 환승 귀가 경로
- 지하철 막차 정보
- 비용 정산
- Redis 캐시
- OAuth2 로그인

## 가장 어려웠던 부분

### 환승을 포함한 막차 계산

첫 번째 노선의 막차를 탈 수 있다고 전체 귀가가 가능한 것은 아니었다. 환승역에 도착했을 때 다음 노선의 막차가 끝났다면 실제 경로는 성립하지 않는다.

그래서 경로를 하나의 문자열로 처리하지 않고 **이동 구간과 환승 흐름 단위**로 다루도록 구조를 정리했다.

### 외부 API 응답 정리

외부 API 응답은 화면에서 바로 사용하기 어려운 경우가 있었다. 역 이름 중복, 안내 문구, 구간 데이터 등을 사용자에게 보여줄 형태로 정리해야 했다.

### 캐시와 최신 데이터

Redis 캐시는 외부 API 반복 호출을 줄이는 데 도움이 되지만 새로고침이나 기준 변경에서는 오래된 데이터를 그대로 보여주면 안 된다. 일반 조회와 새로고침을 구분해 최신 데이터를 다시 확인하도록 개선했다.

## 배운 점

외부 API를 연결하는 프로젝트에서는 API를 호출하는 것보다 **서로 다른 데이터 형식을 우리 서비스의 도메인 모델로 정리하는 과정**이 더 중요할 수 있다는 것을 배웠다.
