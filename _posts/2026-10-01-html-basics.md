부트캠프에서 처음 웹 화면을 만들면서 HTML의 역할을 정리했다.

## HTML은 무엇을 하는가

HTML은 웹 페이지의 **구조와 의미**를 표현한다. 화면의 색상이나 동작보다 먼저 문서가 어떤 요소로 구성되는지를 정의한다.

```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <title>My Page</title>
</head>
<body>
  <h1>Hello</h1>
  <p>첫 번째 문장입니다.</p>
</body>
</html>
```

## 자주 사용한 요소

- `h1 ~ h6` : 제목
- `p` : 문단
- `a` : 링크
- `img` : 이미지
- `ul`, `ol`, `li` : 목록
- `form`, `input`, `button` : 사용자 입력
- `table` : 표

특히 `form`은 서버에 데이터를 전달하는 웹 애플리케이션의 기본 입력 구조라서 이후 Servlet과 연결할 때 중요했다.

## 배운 점

HTML을 단순히 화면을 만드는 문법으로 보기보다 **브라우저가 문서를 해석할 수 있도록 구조를 만드는 언어**로 이해하는 것이 중요했다.

## 더 깊게 이해하기: HTML은 콘텐츠의 구조를 표현한다

HTML 요소는 화면을 꾸미는 용도만이 아니라 콘텐츠의 의미와 관계를 표현한다. 제목은 제목 요소로, 목록은 목록 요소로, 버튼 동작은 버튼으로 표현하면 브라우저와 보조 기술이 문서 구조를 더 정확히 이해할 수 있다. CSS로 비슷하게 보이게 만드는 것과 의미적으로 올바른 문서를 만드는 것은 다른 일이다.

폼을 작성할 때는 입력 요소마다 목적을 설명하는 label을 연결하고, 버튼이 제출인지 단순 동작인지 명시한다. 이미지에는 문맥에 맞는 대체 텍스트를 제공하고, 장식용 이미지라면 불필요한 설명이 읽히지 않도록 한다.

### 실습 점검
- 제목 단계가 문서 구조를 따라 자연스럽게 이어지는가?
- 링크는 이동, 버튼은 동작이라는 역할을 지키는가?
- 입력 필드의 label이 실제 입력 요소와 연결되어 있는가?
- 마우스 없이 Tab과 Enter로 주요 기능을 사용할 수 있는가?

접근성은 마지막에 덧붙이는 장식이 아니라 HTML 구조를 처음 작성할 때부터 고려할 설계 조건이다.
