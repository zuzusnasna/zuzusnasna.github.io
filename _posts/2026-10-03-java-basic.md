부트캠프에서 Java 문법을 익히면서 이후 Spring을 이해하기 위한 기본기를 정리했다.

## 기본 구성

Java 프로그램은 클래스와 메서드를 중심으로 구성된다.

```java
public class Main {
    public static void main(String[] args) {
        int age = 20;
        if (age >= 20) {
            System.out.println("성인");
        }
    }
}
```

## 학습한 핵심 문법

- 변수와 자료형
- 조건문과 반복문
- 배열
- 메서드
- 문자열 처리
- 입력과 출력

문법 자체를 외우는 것보다 반복문, 배열, 메서드를 조합해 작은 문제를 직접 해결하는 방식으로 익혔다.

## 배운 점

Spring Boot를 사용하면 많은 부분이 프레임워크에 의해 감춰지지만 결국 요청을 처리하는 코드는 Java이기 때문에 기본 문법과 객체지향 개념이 기반이 된다는 점을 느꼈다.

## 더 깊게 이해하기: 문법보다 값과 참조의 차이를 이해하기

자바 변수는 기본형 값 자체를 저장하는 경우와 객체를 가리키는 참조값을 저장하는 경우가 있다. 두 변수가 같은 객체를 참조하면 한쪽에서 객체 상태를 바꾼 결과가 다른 쪽에서도 관찰될 수 있다. 반면 참조 변수에 다른 객체를 대입하는 것은 기존 객체 자체를 바꾸는 일과 다르다.

메서드 인자 전달은 모두 값에 의한 전달이다. 객체를 전달할 때 복사되는 값은 객체 참조이므로 메서드 안에서 객체 상태를 바꿀 수 있지만, 매개변수에 다른 객체 참조를 대입해도 호출자의 변수가 새 객체를 가리키게 되지는 않는다.

### 직접 확인할 실습
- 기본형 변수와 객체 참조 변수를 복사한 뒤 각각 값을 바꾸어 결과를 비교한다.
- `==`와 `equals()`가 각각 무엇을 비교하는지 확인한다.
- 문자열을 반복해서 수정할 때 String과 StringBuilder의 차이를 관찰한다.
- 변수의 유효 범위와 객체의 생명 주기를 구분한다.

이런 차이를 이해하면 컬렉션, 메서드 호출, 객체지향 설계에서 발생하는 예상 밖의 상태 변경을 설명하기 쉬워진다.
