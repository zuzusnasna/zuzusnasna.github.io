오늘은 Java가 어떤 언어인지, 실행 방식이 C/C++과 어떻게 다른지부터 정리했다.

## 1. Java 프로그래밍이란?

Java는 객체지향 프로그래밍 언어다. 소스 코드를 바로 운영체제에서 실행하는 것이 아니라 컴파일해서 바이트코드로 만든 다음 JVM이 실행한다.

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello Java");
    }
}
```

실행 흐름은 다음과 같다.

```text
Main.java
   ↓
javac
   ↓
Main.class
   ↓
JVM
   ↓
실행
```

JVM이 운영체제에 맞는 실행 환경을 제공하기 때문에 같은 Java 바이트코드를 여러 운영체제에서 실행할 수 있다.

## 2. Java와 C/C++의 차이

C/C++은 소스 코드를 컴파일하고 링크해서 운영체제에서 실행할 파일을 만든다.

```text
C/C++
소스 코드 → 컴파일 → 링크 → 실행 파일 → 운영체제
```

Java는 바이트코드를 만들고 JVM이 실행한다.

```text
Java
소스 코드 → 컴파일 → 바이트코드 → JVM → 실행
```

Java에서는 C/C++처럼 별도의 링크 단계가 핵심 실행 과정에 포함되지 않는다.

메모리 관리도 차이가 있다. C/C++에서는 개발자가 직접 메모리를 해제하는 경우가 있지만 Java에서는 Garbage Collector가 더 이상 사용하지 않는 객체를 찾아 메모리를 회수한다.

## 3. Java의 장단점

장점:

- JVM을 이용해 플랫폼에 독립적으로 실행할 수 있다.
- 객체지향 프로그래밍을 지원한다.
- Garbage Collector가 메모리 관리를 담당한다.
- 서버 개발에 사용할 수 있는 라이브러리와 프레임워크가 많다.

단점:

- JVM 자체의 메모리와 실행 비용이 필요하다.
- GC 동작이 애플리케이션 성능에 영향을 줄 수 있다.
- C/C++처럼 메모리를 직접 세밀하게 제어하기 어렵다.

Java를 이해할 때는 문법만 보는 것보다 `소스 코드 → 바이트코드 → JVM`으로 이어지는 실행 구조를 같이 보는 것이 중요했다.
