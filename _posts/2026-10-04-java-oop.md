오늘은 객체지향을 이해하기 전에 필요한 클래스, 객체, 인스턴스와 접근 제어자를 정리했다.

## 1. 접근 제어자

Java에서는 클래스의 멤버를 어디까지 접근할 수 있는지 접근 제어자로 지정할 수 있다.

```text
public
protected
default
private
```

### public

어디에서든 접근할 수 있다.

```java
public class Member {
    public String name;
}
```

### private

선언한 클래스 내부에서만 접근할 수 있다.

```java
class Member {
    private String name;

    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }
}
```

외부에서 `name`을 직접 수정하지 못하게 하고 메서드를 통해 접근하도록 만들 수 있다.

### protected

같은 패키지에서는 접근할 수 있고, 다른 패키지에서는 상속 관계를 통해 접근할 수 있다.

### default

접근 제어자를 지정하지 않은 경우다. 같은 패키지 안에서 접근할 수 있다.

| 구분 | 같은 클래스 | 같은 패키지 | 자식 클래스 | 외부 패키지 |
|---|---|---|---|---|
| public | O | O | O | O |
| protected | O | O | O | △ |
| default | O | O | X | X |
| private | O | X | X | X |

## 2. 클래스와 인스턴스

클래스는 객체를 만들기 위한 설계도처럼 볼 수 있다.

```java
class Member {
    String name;

    void hello() {
        System.out.println(name);
    }
}
```

실제로 객체를 만들 때는 `new`를 사용한다.

```java
Member member1 = new Member();
Member member2 = new Member();

member1.name = "홍길동";
member2.name = "김철수";
```

`Member`는 클래스이고 `member1`, `member2`는 `Member`로 생성된 인스턴스다.

같은 클래스로 만들어졌더라도 서로 다른 객체이기 때문에 각각 다른 `name` 값을 가질 수 있다.

```text
Member 클래스
      │
 ┌────┴────┐
 ↓         ↓
member1   member2
홍길동     김철수
```

객체를 여러 개 만들었을 때 상태가 서로 분리된다는 점을 확인하는 것이 클래스와 인스턴스의 차이를 이해하는 데 중요했다.
