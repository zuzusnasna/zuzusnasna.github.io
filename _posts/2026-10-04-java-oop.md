Java를 공부하면서 가장 중요한 전환점은 데이터를 변수로만 보는 것이 아니라 **객체의 상태와 행동으로 묶어 생각하는 것**이었다.

## 클래스와 객체

```java
class User {
    private String name;

    public User(String name) {
        this.name = name;
    }

    public void hello() {
        System.out.println(name + "님 안녕하세요.");
    }
}
```

## 상속과 다형성

상속은 공통 기능을 재사용하고, 다형성은 부모 타입으로 여러 구현을 다룰 수 있게 한다.

```java
Animal animal = new Dog();
animal.sound();
```

실제 프로젝트에서는 인터페이스와 다형성을 이용하면 구현체가 바뀌어도 사용하는 쪽의 코드를 크게 바꾸지 않을 수 있다.

## 인터페이스

인터페이스는 기능에 대한 계약을 정의한다. Spring에서 서비스나 저장소 계층을 분리해 설계할 때도 이 사고방식이 이어진다.

## 정리

객체지향의 핵심은 문법보다 **책임을 어디에 둘 것인가**를 결정하는 데 있다고 정리했다.
