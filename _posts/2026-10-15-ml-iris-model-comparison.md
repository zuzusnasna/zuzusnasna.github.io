Iris 데이터셋으로 여러 분류 모델을 비교하면서 모델별 결과가 어떻게 달라지는지 확인했다.

## 데이터 준비

중복 데이터를 하나 제거한 뒤 클래스별 데이터 수는 다음과 같았다.

- Target 0: 50
- Target 1: 50
- Target 2: 49

훈련/테스트 데이터는 `test_size=0.2`, `random_state=20`으로 분리했다.

## 모델 결과

| 모델 | 정확도 |
|---|---:|
| KNN (`n_neighbors=7`) | 0.97 |
| SVC | 1.00 |
| Logistic Regression | 1.00 |
| Decision Tree (`max_depth=3`) | 0.93 |

단순히 정확도가 가장 높은 모델만 고르는 것이 아니라 데이터 크기와 모델의 특성, 과적합 가능성까지 함께 봐야 한다는 점을 배웠다.

## 예측 확인

`[5.1, 3.5, 1.4, 0.2]`는 setosa로, `[6.3, 3.3, 6.0, 2.5]`는 virginica로 예측되는 것을 확인했다.

작은 데이터셋에서도 전처리 → 분할 → 학습 → 평가 → 실제 샘플 예측의 흐름을 직접 실행해 본 것이 가장 큰 수확이었다.

## 더 깊게 이해하기: 정확도 하나만으로 모델을 고르면 안 된다

Iris 데이터셋은 작고 정돈되어 있어 여러 분류 모델을 빠르게 비교하기 좋지만, 이 데이터셋의 높은 정확도가 실제 서비스 데이터에서도 같은 성능을 낸다는 뜻은 아니다. 학습·테스트 분리를 통해 처음 보는 데이터에 대한 일반화 성능을 추정하고, 전처리와 모델 선택 과정에서 테스트 데이터를 반복적으로 참고하지 않아야 한다.

KNN은 주변 데이터의 거리와 이웃 수에 영향을 받고, SVM은 커널과 정규화 파라미터에 영향을 받으며, 결정 트리는 깊이가 커질수록 학습 데이터에 과적합할 수 있다. 로지스틱 회귀는 선형 결정 경계를 기반으로 하므로 데이터 분포에 따라 적합성이 달라진다.

### 실험 기록에 남길 항목
- train/test 분리 기준과 random_state
- 모델별 하이퍼파라미터와 전처리 방법
- 정확도 외에 클래스별 precision, recall, F1-score
- 혼동 행렬에서 어떤 클래스가 서로 헷갈렸는지
- 데이터가 작거나 중복된 경우 평가 결과가 얼마나 흔들릴 수 있는지

모델 비교는 가장 높은 숫자를 고르는 일보다 데이터와 평가 방식이 결과를 어떻게 만들었는지 이해하는 과정이다.
