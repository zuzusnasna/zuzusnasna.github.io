상태나 유형처럼 사용할 수 있는 값이 정해져 있다면 문자열이나 숫자 상수보다 `enum`을 사용하는 편이 안전하다. Enum은 정해진 상수 집합을 하나의 타입으로 표현한다.

## 1. Enum 기본 선언

```java
enum OrderStatus {
    READY,
    PAID,
    SHIPPING,
    COMPLETED,
    CANCELED
}
```

Enum 타입의 변수에는 해당 Enum에 선언된 값만 대입할 수 있다.

```java
OrderStatus status = OrderStatus.READY;

if (status == OrderStatus.READY) {
    System.out.println("결제 대기 중");
}
```

문자열로 상태를 관리하면 오타가 있어도 컴파일 단계에서 확인하기 어렵다.

```java
String status = "READDY"; // 오타여도 문자열 자체는 유효
```

Enum을 사용하면 선언되지 않은 값을 대입하는 실수를 컴파일 단계에서 방지할 수 있다.

## 2. Enum에 필드와 생성자 추가하기

Enum은 단순한 상수 목록뿐 아니라 필드, 생성자, 메서드도 가질 수 있다.

```java
enum OrderStatus {
    READY("결제 대기"),
    PAID("결제 완료"),
    SHIPPING("배송 중"),
    COMPLETED("배송 완료");

    private final String description;

    OrderStatus(String description) {
        this.description = description;
    }

    public String getDescription() {
        return description;
    }
}
```

사용 예시는 다음과 같다.

```java
OrderStatus status = OrderStatus.PAID;
System.out.println(status.getDescription()); // 결제 완료
```

Enum 생성자는 일반적으로 외부에서 직접 호출할 수 없으며, 각 상수 선언에 전달한 값으로 초기화된다.

## 3. 자주 사용하는 Enum 메서드

| 메서드 | 역할 |
|---|---|
| `values()` | 선언된 모든 상수를 배열로 반환 |
| `valueOf(String)` | 이름이 일치하는 상수를 반환 |
| `name()` | 상수의 선언 이름 반환 |
| `ordinal()` | 선언 순서를 0부터 반환 |

```java
for (OrderStatus status : OrderStatus.values()) {
    System.out.println(status.name());
}

OrderStatus status = OrderStatus.valueOf("PAID");
System.out.println(status); // PAID
```

`valueOf()`는 이름이 정확히 일치하지 않으면 `IllegalArgumentException`을 발생시킨다.

## 4. ordinal()을 업무 코드에 저장하지 않기

`ordinal()`은 선언 순서를 숫자로 반환한다. 하지만 Enum 항목을 추가하거나 순서를 변경하면 숫자의 의미가 달라질 수 있다.

따라서 DB에 저장할 상태 코드나 외부 API에 전달할 값으로 ordinal을 사용하는 것은 피하는 편이 좋다. 별도의 코드를 필드로 관리하는 방식이 안전하다.

```java
enum OrderStatus {
    READY("R"),
    PAID("P"),
    COMPLETED("C");

    private final String code;

    OrderStatus(String code) {
        this.code = code;
    }

    public String getCode() {
        return code;
    }
}
```

이렇게 하면 Enum 선언 순서를 바꾸더라도 업무 코드 값은 유지할 수 있다.

## 5. Enum을 사용하는 상황

- 주문 상태: 결제 대기, 결제 완료, 취소
- 회원 권한: USER, ADMIN
- 게시글 공개 상태: PUBLIC, PRIVATE
- 결제 수단: CARD, BANK_TRANSFER

값의 종류가 고정되어 있고 각 값이 의미를 가져야 하는 경우 Enum을 사용하면 타입 안정성과 가독성을 높일 수 있다.

## 정리

Enum은 정해진 상수 집합을 타입으로 표현한다. 단순 문자열보다 허용 가능한 값을 명확히 제한할 수 있고, 필드와 메서드를 추가해 각 상수의 속성도 관리할 수 있다. 다만 선언 순서에 의존하는 ordinal 값은 영속 데이터나 외부 시스템의 코드로 사용하지 않는 것이 좋다.
