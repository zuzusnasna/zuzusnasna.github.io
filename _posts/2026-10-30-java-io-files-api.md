## Path와 Files

Path는 파일 시스템 경로를 표현하고 Files는 경로를 대상으로 파일 작업을 수행하는 API다. 디렉터리 생성, 파일 읽기·쓰기, 복사, 이동, 삭제 등을 제공한다.

## 파일 읽기와 쓰기

작은 텍스트 파일은 readString()과 writeString()으로 간단히 처리할 수 있다. 큰 파일은 readAllBytes() 등으로 한 번에 메모리에 올리기보다 스트림이나 채널을 이용해 나누어 처리한다.

## 복사와 이동

Files.copy()와 Files.move()를 이용해 파일을 복사하거나 이동할 수 있다. 파일 시스템이나 옵션에 따라 이동이 원자적으로 처리되지 않을 수 있으므로 관련 예외를 고려한다.

## 삭제와 예외

delete()는 대상이 없으면 예외가 발생할 수 있다. deleteIfExists()는 대상이 존재할 때 삭제하고 결과를 반환한다. 권한 부족이나 다른 프로세스의 파일 사용도 예외 원인이 될 수 있다.

## 업로드 기능에서 주의점

사용자가 전달한 파일명을 그대로 서버 경로에 붙이지 않는다. 경로 조작(Path Traversal), 파일 크기 제한, 확장자와 실제 콘텐츠 검증, 저장 위치 분리 등을 고려해야 한다.
