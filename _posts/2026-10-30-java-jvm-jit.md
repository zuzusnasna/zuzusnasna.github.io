## Java 실행 과정

Java 소스 코드는 컴파일러를 거쳐 바이트코드가 되고, JVM이 이를 실행한다. JVM은 인터프리터와 JIT(Just-In-Time) 컴파일러를 활용한다.

## 인터프리터와 JIT

인터프리터는 바이트코드를 실행한다. 자주 실행되는 코드 영역은 실행 중 수집한 정보를 바탕으로 JIT 컴파일러가 기계어로 컴파일할 수 있다. 반복 실행되는 구간을 HotSpot이라고 부른다.

## 실행 중 최적화

JIT 컴파일러는 실제 실행 정보를 활용해 인라이닝 등의 최적화를 수행할 수 있다. 최적화에 사용한 가정이 깨지면 Deoptimization이 발생해 다시 해석 방식으로 돌아갈 수도 있다.

## 성능 측정 시 주의점

JVM은 실행 중 최적화가 진행되므로 한 번 실행한 시간만으로 성능을 비교하면 부정확할 수 있다. 충분한 워밍업과 반복 측정이 필요하며, 정밀한 벤치마크에는 JMH 같은 도구를 고려한다.

## 백엔드에서의 의미

서버의 장시간 실행 성능은 JVM 최적화의 영향을 받는다. 성능 문제를 분석할 때 코드뿐 아니라 워밍업, GC, 스레드, CPU 사용률도 함께 확인한다.
